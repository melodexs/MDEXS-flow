# Cloud database: migrations and seeds

Versioned cloud database (Neon PostgreSQL) artifacts.

- Migration scripts are generated by Alembic into
  `services/api/alembic/versions/` (that is the authoritative location,
  configured by `services/api/alembic.ini`).
- This folder documents and seeds the cloud database. Seeds contain only
  synthetic, license-free reference data — never real user data or
  copyrighted media references.

Run migrations from `services/api/`:

```bash
.venv/bin/alembic upgrade head
```

`DATABASE_URL` must be set locally (e.g. a Neon branch); it is never committed.
